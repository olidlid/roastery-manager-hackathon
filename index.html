Label Layout

Visible fields on the roasting log & packed coffee stickers (both 50×25mm)

The barcode (encoding the batch code) always prints.

The barcode (encoding the lot code) always prints.

Only height needs tuning per printer — the barcode width is locked to whole printer dots so the bars stay scannable. Label is 25mm tall total, so leave room for the text lines below.

Labels print portrait and cropped until the printer itself is set up. This is a Windows setting — the app cannot change it.

  1. In the Zebra driver's Printing preferences, give the 50×25mm size a NAME under Stocks. Do not leave it on "User defined" — an unnamed size is invisible to Chrome.
  2. Printer properties → Advanced → Printing Defaults → Orientation = Landscape. It must be Printing Defaults, not Printing preferences — Chrome reads the first one.
  3. Close Chrome completely, then reopen it. Paper sizes are only read at startup.

To set up another computer, use the driver's Import/Export settings tab instead of repeating these steps by hand.
